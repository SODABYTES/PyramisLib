# PyramisLib
PyramisLib is a library version of Daniel Sosa's Pyramis game, meant to serve as a foundation for any Pyramis games going forward.
It only contains game logic and nothing more, so it's up to you to represent the information with graphics and sounds and that sort of thing.

Right now the intended use for this repository is to just add it as a submodule in your own project.
There are no build system files to make things more convenient for you... sorry...
but if you just add everything from the `src/` directory it should be fine.
As for headers in your own code, just including `PyramisLib.h` should work.
